Are doomers correct?

Tech job listings in India, counted every night and extrapolated to 31 December 2027.

Inspired by @usr_bin_roygbiv's website (original site, X profile), which tracks the United States. This is an independent rebuild covering India and the United States, with its own data collection and its own forecasting model. No affiliation.

Method and caveats

Collection. Every night at midnight a worker queries public job boards through JobSpy and stores what it finds in SQLite. Every run issues the same set of queries — sampling a rotating subset would be cheaper, but then the count would move with the rotation rather than with the market.

The shaded region. Days before our first scrape are reconstructed from posting dates. We can only reconstruct listings that were still live when we first looked, so that stretch understates the past and slopes upward artificially. It is shown for context and is never used to fit the model.

The forecast. For the first month of collected data the projection is an ordinary least-squares line. After that it switches to a non-seasonal ARIMA(p, d, q), fitted by Hannan–Rissanen and selected by AICc, on a trailing window of recent days. It is fitted in log space and damped, so it flattens instead of running off the chart. The band is a 95% prediction interval.
